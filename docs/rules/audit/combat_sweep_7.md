# Combat audit — sweep 7: creature spell effects (SPELL_ABILITY_* / SPELL_EFFECT_* ids)

Per-ID rows merged into `docs/rules/AUDIT_COMBAT.md` by `tools/re/audit/ledger.py` (rows here override the earlier
fragments). Exe references are H5_Game.exe (GOG 3.1) addresses, analysed headless with Ghidra 12.1.4 (private project
copy). Code: `src/H5.Combat/Battle.Sweep7.cs`; tests: `tests/H5.Combat.Tests/AuditSweep7Tests.cs`.

## Effect-container methods used below

`CCombatCreature` (RTTI `.?AVCCombatCreature@NWorld@@`, effect interface vtable 00e4fba4): vf 0x28 GetEffect(id);
vf 0x25c / 0x260 add (count / time duration); **vf 0x268 = FUN_00a72c80**: decrement the effect's count (+0x20) by one
via FUN_004e3dd0 and remove it below 1 (permanent 0x7fffffff / 0x7ffffffd untouched); **vf 0x270 = FUN_00a72d30**
(id, time, force): remove every instance — 0x7fffffff / 0x7ffffffd survive unless force; 0x7ffffffe ("whole battle")
does not. Creature turn start (FUN_00bbcb40 / FUN_00bbcaa0, kind 1) → FUN_00bbc8e0: Dash (0xb0) vf 0x268; Battle Frenzy
(0x112), Berserker Rage (0xf5) and Preparation (0x11e) vf 0x270 force; a Defile Magic stack (ability 0x6d) removes the
0x146 effects it placed (vf 0x30 list, vf 0x270, vf 0x2a4); then FUN_00bbc510, the DoT ticks FUN_00bbb900 (vf 0x4c ≠ 1)
and Gating FUN_00bbb390. The "disabled" helper FUN_004e4a20 (time left FUN_004e4920) is Blind 0x13, Frozen 0xc9,
Sabotage 0x14a, Sleeping Strike 0x150 or being seduced (linked 0x148, FUN_004e48a0).
