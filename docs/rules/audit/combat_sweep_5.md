# Combat audit — sweep 5: racial and might perks (Gating, Hellfire, Holy Charge, Mark of the Damned, Preparation)

Per-ID rows merged into `docs/rules/AUDIT_COMBAT.md` by `tools/re/audit/ledger.py` (rows here override the earlier
fragments). Exe references are H5_Game.exe (GOG 3.1) addresses, analysed headless with Ghidra 12.1.4 (private project
copy). Code: `src/H5.Combat/Battle.Sweep5.cs`; tests: `tests/H5.Combat.Tests/AuditSweep5Tests.cs`.

Hero "special abilities" are hero spells: learning the perk adds the spell to the hero (FUN_00b54770: HOLY_CHARGE → spell
0x35, DEMONIC_STRIKE → 0x38, MULTISHOT → 0x3d, IMBUE_ARROW → 0x3e, ENCOURAGE → 0x34), the linked ones become effects on
the target creature (FUN_004e3ac0 lists 0x35 / 0x38 as never dispelled) found again with FUN_00a6e270(unit, spell), and
the linked strikes go through FUN_008cfb50 → FUN_008cf270 (the hero strike) with the spell id, whose damage is
FUN_00bc1b90(spell): level + 3 for 0x35 / 0x38 / 0x3d / 0x131, plain level for 0x124, Deadeye's +3 only for the plain
strike (0).
