# Combat audit — sweep 15: Battle Dive timing, the ATB clock, Defile Magic roll

Per-ID rows merged into `docs/rules/AUDIT_COMBAT.md` by `tools/re/audit/ledger.py` (fragments are read in natural
order, so rows here override sweep 1–14). Exe references are H5_Game.exe (GOG 3.1) addresses, analysed headless with
Ghidra 12.1.4 (private project copy), disassembly read directly where the decompiler loses registers. Tests are in
`tests/H5.Combat.Tests/AuditSweep15Tests.cs`; code in `src/H5.Combat/Battle.Sweep15.cs`.

Facts used below. Creature unit interface (vtable 00e4fba4): vf 0x50 = FUN_008a3320 (the byte of a per-unit
(time, value) timeline at [this − 0x94] in force at the given time, FUN_008ace60; written by vf 0xd4 = FUN_008a6330(time,
value), which appends only a changed value), vf 0x174 = FUN_00a6a060, vf 0x178 = 008ae630 → FUN_00a6a260, vf 0x17c =
FUN_00a6e440, vf 0x180 = FUN_00a6a210. FUN_008d5eb0 / FUN_008d0ec0 (named as the Battle Dive mover hook in sweep 14) are the
combat AI's look-ahead ("CombatAI start think", FUN_008d6a70), not the game's movement: they simulate the same 0x9b finish.
