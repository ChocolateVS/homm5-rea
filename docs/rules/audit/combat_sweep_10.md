# Combat audit — sweep 10: Guardian Angel, Balor placement, moat damage, Encourage, Howl / Soulfire traces

Per-ID rows merged into `docs/rules/AUDIT_COMBAT.md` by `tools/re/audit/ledger.py` (fragments are read in natural
order, so rows here override sweep 1–9). Exe references are H5_Game.exe (GOG 3.1) addresses, analysed headless with
Ghidra 12.1.4 (private project copy). Tests are in `tests/H5.Combat.Tests/AuditSweep10Tests.cs`; code in
`src/H5.Combat/Battle.Sweep10.cs`.

Facts used below: FUN_00a34ca0 is Eval(spell ECX, mastery EDX, power on the stack) = power · PerPower + Base of the spell
record's +0x94 table (12-byte items, index clamped to the table, FUN_00a34c40). FUN_00a34110 maps a spell to its base
spell (mass / empowered variants), FUN_00a34100 tells an empowered spell. The combat hero's unit vtable is 00e8499c
(vf 0x224 = thunk 00bc2fc0 → FUN_00bbf610). The unit vf 0x244 (spell power) of a creature is FUN_00a6a7e0 over the
creature's own FUN_008a3960 (CCombatCreature primary vtable 00e4ff2c slot 9): FUN_004bad20 = max(1, round(21 · log10(10
+ (count · 10) / weekly growth) − 22)).
