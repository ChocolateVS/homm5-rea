# Combat audit — school spells and spell immunities (spells part S)

Per-ID rows merged into `docs/rules/AUDIT_COMBAT.md` by `tools/re/audit/ledger.py` (rows here override those of
`combat_spells.md` / `combat_spells_r.md`). Exe references are H5_Game.exe (GOG 3.1) addresses, analysed headless with
Ghidra 12.1.4 (`tools/re/audit_spells_s/ghidra.sh`, private project copy). Tests are in
`tests/H5.Combat.Tests/AuditSpellSTests.cs`; the engine side of the immunity port is `src/H5.Combat/Battle.SpellAuditS.cs`.

Spell immunity = FUN_0097c9f0 returning 100 (FUN_0097d2a0 then sets protection 1.0; only FUN_004e5cb0 "damage spells" get
Irresistible Magic's reduction). FUN_0097c9f0 works on the base spell id (FUN_00a34110: FUN_00a33e20 maps the mass
spells 0xd2..0xdd, FUN_00a33f70 the empowered ones 0xdf..0xe9 / 0x12a to their base).
