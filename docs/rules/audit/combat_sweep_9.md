# Combat audit — sweep 9: Berserker Rage, effect stacking, turn-order ties, Howl

Per-ID rows merged into `docs/rules/AUDIT_COMBAT.md` by `tools/re/audit/ledger.py` (rows here override the earlier
fragments). Exe references are H5_Game.exe (GOG 3.1) addresses, analysed headless with Ghidra 12.1.4 (private project
copy). Tests are in `tests/H5.Combat.Tests/AuditSweep9Tests.cs`; code in `src/H5.Combat/Battle.Sweep9.cs`.

Facts used below: the creature effect interface (CCombatCreature vtable 00e4fba4, thunks 008ae8xx → this − 0x94) has
vf 0x25c = FUN_00a73d40 (add, count), vf 0x260 = FUN_00a73da0 (add, time), vf 0x268 = FUN_00a72c80 (count − 1, removed
below 1), vf 0x270 = FUN_00a72d30 (remove, force), vf 0x200 = FUN_008aa960 (turn-start reset: FUN_008a6910 Take Roots
release + retaliation flag), vf 0x204 = FUN_008a6be0 (the Defend handler). Adding an effect (FUN_00a73ab0) merges it into
an existing one with the same id through FUN_004e4a80(new, 0): the value +0x20 is SUMMED when FUN_004e3990(id) holds
(ids 0xd, 0x10, 0xac, 0xb3, 0xd1, 0x112, 0x12b — jump tables 004e39d4 / 004e39dc, 004e3a84 / 004e3a8c), else replaced;
+0x2c (expiry time) = min(old, new). On the creature ability interface (vf 0x6c) vf 0x2c / vf 0x30 are the ability
CHARGES (get / set), as Repair and Random Caster use them.
