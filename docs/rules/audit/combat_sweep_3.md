# Combat audit — sweep 3: creature abilities (categories, immunities, activated abilities, vulnerability auras)

Per-ID rows merged into `docs/rules/AUDIT_COMBAT.md` by `tools/re/audit/ledger.py` (rows here override the earlier
fragments). Exe references are H5_Game.exe (GOG 3.1) addresses, analysed headless with Ghidra 12.1.4 (private project
copy). Tests are in `tests/H5.Combat.Tests/AuditSweep3Tests.cs`; engine code in `src/H5.Combat/Battle.Sweep3.cs`.

Facts used below: war machines answer HasAbility(MECHANICAL) (vtable 00e70594 slot 0x28c → FUN_00a75160: `id == 9`; the
engine gives them the ability in BattleSetup). FUN_0097f610 is the target check of ability spells (school SPECIAL, reached
from the application check FUN_00982010 when FUN_00a34610 holds); creature strike effects applied through FUN_00a5ddb0 /
FUN_00bbf160 build a cast record with +0x38 = 0 (traced from the pushes at 00a5dde9..00a5de02 and 00bbf168..00bbf1a0), so
FUN_00bbf000 runs that check for the spells of FUN_00a34130 (0x34, 0x36, 0x9c, 0x9d, 0xa0, 0xf6) and the others of school
≠ SPECIAL. RPGStats offsets from `tools/re/out/rpg_combat.txt`. Both shipped DefaultStats (3.1 and MMH55) were compared
for the constants named.
