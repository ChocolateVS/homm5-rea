cell is the *unit's* vf 8 (creature 00e4fba4 +8 = 008aead0, hero 00e8499c +8 = 00bc3200, both → FUN_008acdc0 = the
unit's field −0x78), the CCombat object (vtable 00e79d3c): vf 0x44 = 00af1450 (field size W, H), vf 0x6c = FUN_00af14e0
(cell → world): with o = the virtual base's vf 0x2c (origin) and H from vf 0x44, X = o.x + 2(x − 1.5),
Y = o.y − 2H + 2(y + 0.5) (DAT_00e3a3ac = 1.5, DAT_00e0ab70 = 0.5), Z = the virtual base's vf 0x38(X, Y) — the terrain
height. A unit's cell (vf 0x40 = 008ae1e0 → FUN_00a6a040) is its footprint's maximum corner: its cell list (vf 0xc4 =
008ae340 → FUN_00a6d870 → FUN_00a744f0) is (x − i, y − j), i outer, j inner, for a size above 1.
