# Random map generator audit ledger

Every stage of the random map generator (`src/H5.Rmg`) compared with `H5_Game.exe` (Ghidra 12.1.4, image VAs; project
copied from `tools/ghidra-projects/rmg`, scripts in `tools/rmgre/scripts`) and the original data. The target is the
stock 3.1 engine running either the stock templates or MMH 5.5's 94 template files (`MMH55-Templates.pak`, 72 new);
MMH55's `MMH55_Utility.exe` RMG byte patches are out of scope (docs/mmh55/PLAN.md §0). Status: **MATCH** (already as
the exe), **FIXED** (changed to match), **GAP** (known difference or not built), **UNVERIFIED** (implemented from data or
observation, exe path not traced). Rows carrying two statuses count once for each. Stage overview and formulas:
`docs/rules/RMG.md`.

Rows at 2026-11-10: 64 FIXED, 8 MATCH, 7 GAP, 3 UNVERIFIED.

Tools: `h5tool rmg-stats [seeds] [--threads=N] [--filter=s] [--max-players]` generates every template at every
size / underground / player count the RMG screen lists it for; `h5tool rmg-ref [--detail] [--terrain [--window=…] [--roadtiles=…] [--hpoint=x,y] [--hdump=dir]] [--reach] [--diverge] [--trace] [--near=x,y,d] [--only=name]` regenerates the user's
stock RMG maps (template, seed, races, monster level and the recorded Resources / Experience levels) and prints
counts (per shared object with `--detail`), the objects equal in creation order, per-layer vertex differences
(`--terrain`; road tiles of both maps with `--roadtiles`), the terrain passability of both maps (`--reach`).

Sweep (MMH 5.5 install, 93 template names from 94 files, 1 seed): **465 runs, 0 failures**, 1010 unreachable objects (1002 in the underground runs: treasures and chests in pockets of the underground statics, see "Underground pockets"; 8 on the surface, see "Surface pockets"; our reachability check over object footprints, the rock not counted), 835 s on 8 threads (Release). With the adventure map's passability (`rmg-stats` "passability": the same per-zone check over `MapFloor.Blocked` — exe 00990800 terrain kinds: chunk 15 holes, cliffs, the underground rock, texture lakes, the frame — plus the object footprints, sea excluded): **1680 unreachable** (1672 in the underground runs, 8 on the surface; 1650 before the lake flags and mountain heights, 2026-10-28). 2026-11-10, after the vertex painting, levelling, shipyards and point lights: 465 runs, 0 failures, 1010 / 1680 unchanged (the sweep runs without the water option; shipyards: test `WaterZonesBuildShipyards`); the nine stock reference maps' counts unchanged (no new draws without water or underground); both unreachable groups are MATCH (rows "Surface pockets", "Unreachable objects (adventure passability)"). 2026-11-10, bit-exact pass (truncated radius / border distance / guard values, mine table): 465 runs, 0 failures; every run draws a new sequence, so the counts moved: 1001 unreachable, 1821 with the adventure passability (1686 underground, 135 surface — 130 of them in 8P-Collar-XL and 8P-Frame-XLu at size 4 / 7 players, seed 8050, whose split zone logs "pure road algo failed"; no connectivity pass in the exe, row "Surface pockets"), 2332 s on 8 threads of a loaded machine. 2026-11-10, x87 pass: 465 runs, **0 failures**, 1039 unreachable, 1813 with the adventure passability (1690 underground, 123 surface — 118 of them the same two seed-8050 runs, 58 + 60: a town-less zone whose network starts at a junction cut off by a border-distance-0 tile, the exe's rule, row "Unreachable objects (adventure passability)"; globally reachable), 1478 s on 8 threads. 2026-11-10, terrain x87 pass (radius, centroid, teleport, stack-pick and treasure-angle chains chopped as well): 465 runs, **0 failures**, 1037 unreachable, 1811 with the adventure passability (1688 underground), 1168 s on 8 threads.
